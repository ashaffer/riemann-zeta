# R136 Nyman `L1 -> Lp` self-improvement gate

Status: this audit corrects an emphasis in the earlier RH-focused Nyman
report.  For a **fixed** zero-free strip, changing the exponent away from
`2` is not a defect: it is exactly what one wants.  The prime number theorem
already gives the endpoint `L1` input, and any fixed gain to `L^(1+delta)`
would prove a fixed strip.

The audit imports the precise arithmetic Nyman--Beurling theorems, proves an
exact `G_n` tail obstruction, isolates the compactly supported
Báez--Duarte collar, and rules out every fixed dilation-equivariant linear
self-improver.  Power weights, convex dilation averages, and finite tail
moment cancellation all pay back their apparent gain at the Mellin detector.
All finite logarithmic Orlicz improvements are already available and are
still insufficient.

There is a potentially useful distributional reformulation: a fixed
weak-`L^q`, `q>1`, rarity estimate for large values of the Mertens function
in reciprocal measure.  Alternatively, one may seek a weak higher-moment
estimate for the exact compact Báez--Duarte collar.  No such estimate is
proved here.

**Subsequent correction.**  The direct Mertens weak-tail target is not
qualitatively weaker than pointwise power cancellation.  Since
`|M(n+1)-M(n)|<=1`, a value `|M(N)|=H` persists on at least `cH`
adjacent integers for an absolute `c>0`.
Consequently reciprocal weak-`L^q`, `q>1`, implies
`M(N)=O(N^(2/(q+1)))`.  Conversely any `M(N)=O(N^theta)`, `theta<1`, gives a
fixed weak exponent.  The exact proof, the minimal normalized-tail
good-lambda condition, and a centered floor-recurrence obstruction are in
[`R136-WEAK-TAIL-GOOD-LAMBDA-AUDIT.md`](R136-WEAK-TAIL-GOOD-LAMBDA-AUDIT.md).
The weak-tail language remains a useful alternate formulation, but it does
not lower the qualitative fixed-power difficulty.

```text
PNT / natural Nyman approximation in L1                    KNOWN
some fixed Lp improvement, p>1                             => FIXED STRIP
Mertens reciprocal weak-Lq estimate, q>1                   EQUIV. TO SOME POINTWISE SAVING; OPEN
G_n exterior tail                                           EXACT gamma(n)/x
tail-corrected G_n and B_n                                  COMPACT COLLARS
fixed dilation-commuting bounded L1 -> Lp map, p>1          ZERO OPERATOR
positive convex dilation smoothing preserving the target   CONCENTRATES AT IDENTITY
power-weight suppression                                    DETECTOR SHIFTS BY SAME POWER
all finite L log^A L improvements                           KNOWN; INSUFFICIENT
generic integer 1-Lipschitz self-improvement                FALSE
fixed zero-free strip                                       NOT PROVED
nonexistence of a fixed strip                               NOT PROVED.       (1.1)
```

## 2. The fixed-strip endpoint that the earlier audit underplayed

Write

```text
rho(u)=u-floor(u),
chi=1_(0,1],
M(x)=sum_(n<=x) mu(n),
M_1(theta)=M(1/theta),       0<theta<=1.                    (2.1)
```

Let `C` be the constrained Nyman space generated by

```text
sum_j c_j rho(theta_j/x),    0<theta_j<=1,
sum_j c_j theta_j=0.                                        (2.2)
```

Beurling's `Lp` theorem says, for every `1<p<infinity`,

```text
chi in closure_Lp(C)
    <=> zeta(s) has no zero in Re(s)>1/p.                   (2.3)
```

Thus a fixed strip `Re(s)>1-eta` is obtained from any fixed

```text
p>1,                 1/p <= 1-eta.                          (2.4)
```

The fact that `p` is not the symmetry exponent `2` matters only when the goal
is all of RH.  For the present fixed-strip goal, the existence of *any*
`p>1` is exactly the right target.

Báez--Duarte's arithmetic form makes the endpoint especially explicit.  For
`p>=1`, a change of variables on each interval
`(1/(n+1),1/n]` gives

```text
||M_1||_p^p
 = integral_0^1 |M(1/theta)|^p dtheta
 = sum_(n>=1) |M(n)|^p/[n(n+1)].                            (2.5)
```

The standard PNT bound `M(x)<<_A x/(log x)^A`, with `A>1`, implies

```text
sum_(n>=1) |M(n)|/[n(n+1)] < infinity.                      (2.6)
```

Báez--Duarte proves the two implications needed here:

```text
||M_1||_p < infinity
   => zeta(s)!=0 for Re(s)>=1/p,                             (2.7)

zeta(s)!=0 for Re(s)>1/p
   => ||M_1||_r<infinity for every 1<r<p.                   (2.8)
```

Consequently the following existence statements are equivalent:

```text
there is a fixed zero-free strip;
there is some p>1 with M_1 in Lp(0,1);
there is some p>1 with
  sum |M(n)|^p/[n(n+1)] < infinity.                         (2.9)
```

This is an imported theorem, not a new claim.  It recasts the exact research
question as an endpoint self-improvement problem:

```text
known:  sum |M(n)|/n^2 < infinity;
wanted: sum |M(n)|^(1+delta)/n^2 < infinity
        for one fixed delta>0.                              (2.10)
```

Unlike a pointwise estimate `M(n)<<n^theta`, (2.10) permits exceptional
large values on sufficiently sparse sets.  That is the main reason this
formulation remains worth keeping.

## 3. The integrated natural approximation and its exact tail

Define the dilation-equivariant integral operator

```text
(Tf)(x)=integral_0^infinity
          f(theta) rho(theta/x) dtheta/theta.                (3.1)
```

For every `1<p<infinity`, `T:Lp->Lp` is bounded.  The integrated Möbius
identity is

```text
lambda(x)=chi(x) log x = T M_1(x),                           (3.2)
```

and Báez--Duarte's natural approximation is

```text
G_n=T(M_1 1_(1/n,1]).                                       (3.3)
```

Put

```text
g(n)=sum_(k<=n) mu(k)/k,
gamma(n)=sum_(k<n) M(k)/[k(k+1)]
        =g(n)-M(n)/n.                                       (3.4)
```

The PNT and partial summation give

```text
integral_0^1 M_1(theta)dtheta=0,
integral_0^(1/n) M_1(theta)dtheta=-gamma(n).                 (3.5)
```

Since `rho(theta/x)=theta/x` whenever `x>=1/n` and
`0<theta<1/n`, (3.2)--(3.5) give the pointwise identity

```text
G_n(x)-lambda(x)=gamma(n)/x,       x>=1/n.                   (3.6)
```

Therefore, for every `p>1`,

```text
||G_n-lambda||_p^p
 >= |gamma(n)|^p integral_(1/n)^infinity x^(-p)dx
 = |gamma(n)|^p n^(p-1)/(p-1).                              (3.7)
```

This is the exact `gamma(n)` obstruction requested in the audit.  It is not
an artifact of Hölder or an absolute-value estimate.  A zero on
`Re(s)=1/p` forces `gamma(n)` not to be `o(n^(-(1-1/p)))`, so (3.7) also
recovers Báez--Duarte's endpoint divergence theorem.

The endpoint statement needs one qualification: `G_n->lambda` in `L1(0,1)`
and pointwise, while its `gamma(n)/x` tail is not integrable on `(1,infinity)`
unless `gamma(n)=0`.  All `p>1` norms above are on `(0,infinity)`, as in the
arithmetic Nyman theorem.

## 4. Tail cancellation is exact, but moves everything into a shrinking collar

The exterior tail can be removed inside the Nyman span.  Define

```text
H_n(x)=G_n(x)-n gamma(n) rho(1/(nx)).                        (4.1)
```

By (3.6),

```text
H_n(x)-lambda(x)=0,             x>=1/n.                     (4.2)
```

Thus `H_n-lambda` is a compact collar at the origin.  Rescaling `x=u/n`
shows exactly what remains:

```text
H_n(u/n)-lambda(u/n)
 =-integral_0^1 M(n/v) rho(v/u) dv/v
  -n gamma(n)rho(1/u),              0<u<1,                  (4.3)

||H_n-lambda||_p^p
 =n^(-1) integral_0^1 |right side of (4.3)|^p du.           (4.4)
```

No available PNT estimate makes (4.4) tend to zero for a fixed `p>1`.
The correction deletes one exterior moment; it does not bound the rescaled
Möbius collar.

The classical Báez--Duarte function is the finite, even cleaner version of
the same operation:

```text
S_n(x)=sum_(k<=n) mu(k)rho(1/(kx)),
B_n(x)=S_n(x)-n g(n)rho(1/(nx)),
E_n(x)=chi(x)+B_n(x).                                      (4.5)
```

Möbius inversion gives

```text
B_n(x)=-1 on [1/n,1],
B_n(x)=0 on (1,infinity),
support(E_n) subset (0,1/n),
||E_n||_1 ->0.                                              (4.6)
```

Moreover `|E_n|<<n` for all sufficiently large `n`: each fractional-part
term is bounded, and `g(n)->0`.  Hence the elementary interpolation bound is

```text
||E_n||_p^p <= ||E_n||_infinity^(p-1)||E_n||_1
             << n^(p-1)||E_n||_1.                          (4.7)
```

Known PNT savings in `||E_n||_1` are subpower in `n`; they do not pay the
fixed factor `n^(p-1)`.  A power gain in (4.7) would already be fixed-strip
strength.

Finite linear combinations of different `G_n` can cancel
`sum_j c_j gamma(n_j)` while maintaining `sum_j c_j=1`.  In operator form
their error is

```text
-T(M_1 w),
w(theta)=sum_j c_j 1_(0,1/n_j)(theta).                      (4.8)
```

For all sufficiently small `theta`, however, `w(theta)=sum_j c_j=1`.
Thus the deepest Möbius tail survives.  The cancellation removes its first
exterior moment and relocates the defect; it does not create an `Lp` bound.
The compact collar (4.6) is already the maximally transparent example of
this phenomenon.

## 5. A useful interpolation target weaker than convergence in a higher norm

Let `epsilon_n=||E_n||_1` and let `1<p<q`.  Ordinary interpolation gives

```text
||E_n||_p^p
 <= epsilon_n^((q-p)/(q-1))
    ||E_n||_q^(q(p-1)/(q-1)).                               (5.1)
```

The strong `Lq` norm can be weakened.  If

```text
W_n=||E_n||_(L^(q,infinity)),                               (5.2)
```

then the layer-cake formula, split where the `L1` and weak-`Lq` tail bounds
cross, gives

```text
||E_n||_p^p
 <= C_(p,q) epsilon_n^((q-p)/(q-1))
              W_n^(q(p-1)/(q-1)).                          (5.3)
```

In particular, a uniform weak-`Lq` bound for one `q>1`, combined with
`epsilon_n->0`, proves `E_n->0` in every `Lp`, `1<p<q`, and hence proves a
fixed zero-free strip by (2.3).

There is an even more direct single-function version.  Since `M_1` is already
in `L1(0,1)`,

```text
M_1 in weak-Lq(0,1) for one q>1
  => M_1 in Lp(0,1) for every 1<p<q
  => a fixed zero-free strip.                               (5.4)
```

In discrete form, the new sufficient target is

```text
sum_(n: |M(n)|>U) 1/[n(n+1)] << U^(-q)                     (5.5)
```

for one fixed `q>1`.  The trivial `|M(n)|<=n` gives only `q=1`.  The
classical Vinogradov--Korobov PNT remainder improves its right side by a
subpower factor of the shape

```text
U^(-1) exp[-c (log U)^(3/5)(log log U)^(-1/5)],             (5.6)
```

after harmless changes of constants, but still supplies no fixed `q>1`.

Estimate (5.5) is a clean distributional proposal.  However, the subsequent
spike-spreading theorem linked at the start of this report shows that its
existence for any fixed `q>1` already implies a pointwise fixed power saving
for `M`.  Sparse exceptional values are allowed relative to a given tail
exponent, but unit increments prevent near-linear spikes from being
arbitrarily sparse.

## 6. No fixed dilation-equivariant linear self-improver exists

Let

```text
(K_a f)(x)=f(ax),       a>=1,                               (6.1)
```

with functions extended by zero outside `(0,1)` when necessary.

### Theorem 6.1 (scaling obstruction)

Let `p>1`.  If a bounded linear map

```text
R:L1(0,infinity)->Lp(0,infinity)                            (6.2)
```

commutes with every `K_a`, then `R=0`.

#### Proof

For `f` in `L1`, commutation and exact scaling give

```text
a^(-1/p)||Rf||_p
 =||K_a Rf||_p
 =||R K_a f||_p
 <=||R|| a^(-1)||f||_1.                                    (6.3)
```

Therefore

```text
||Rf||_p <=||R|| a^(-(1-1/p))||f||_1.                       (6.4)
```

Letting `a->infinity` proves `Rf=0`.  The same proof works on `(0,1)` with
zero extension.  QED.

This rules out, as fixed exponent-raising devices:

* convolution in logarithmic coordinates;
* a fixed Mellin multiplier;
* a fixed linear average of dilations;
* the operator `T` in (3.1), if it were claimed to map `L1` into a higher
  `Lp`.

Indeed `T K_a=K_a T`; it is bounded `Lp->Lp` for each `p>1`, but cannot be a
nonzero `L1->Lp` smoother.

The theorem does not rule out cutoff-dependent, nonlinear, or explicitly
noncommuting arithmetic maps.  Clipping `M_1` before applying `T`, the
cutoff in `G_n`, and the tail correction in (4.1) are examples.  Their
remaining convergence problem is precisely the collar estimate (4.4).

There is also a useful abstract sufficiency check.  Suppose `R_j` are bounded
`L1->Lp`, map the Nyman span into its `Lp` closure, and
`R_j chi->chi` in `Lp`.  Applying `R_j` to the known `L1` approximants and
then taking the two limits proves `chi` lies in the `Lp` Nyman closure.
Thus any such noncommuting approximate identity would prove the desired
strip; constructing it is not a harmless functional-analytic regularization.

## 7. Convex dilation averaging cannot spread the spike and preserve the target

Let `nu` be a probability measure on `[1,infinity)` and

```text
A_nu f=integral K_a f dnu(a).                               (7.1)
```

This positive average preserves the dilation span.  For the target `chi`,
Fubini gives the exact identity

```text
||chi-A_nu chi||_1
 =integral_[1,infinity) (1-1/a)dnu(a).                      (7.2)
```

Consequently, for every `A>1`,

```text
nu([A,infinity))
 <=||chi-A_nu chi||_1/(1-1/A).                              (7.3)
```

If the averaged target tends back to `chi`, the dilation measure must
concentrate at the identity.  A positive average therefore cannot put a
nonvanishing amount of mass on the large dilations needed to spread an
origin collar.  Signed averages evade (7.2), but only through cancellation;
their total variation is the relevant operator norm and becomes the new
conditioning cost.

## 8. Power weights pay back the gain at the zero detector

Let `F` be a constrained Nyman function and `E=chi+F`.  At a zero
`rho_0=beta+i gamma` of zeta, the Mellin transform of `F` vanishes while that
of `chi` is `1/rho_0`.  For `alpha>=0`, Hölder gives

```text
1/|rho_0|
 <=||x^alpha E||_p
   (integral_0^1 x^(q(beta-1-alpha))dx)^(1/q),               (8.1)
```

and the second factor is finite exactly when

```text
beta>alpha+1/p.                                             (8.2)
```

Thus multiplication by `x^alpha` suppresses the collar but shifts the
detected zero-free boundary to the right by exactly `alpha`.

For a collar supported on `(0,1/n)` with

```text
||E_n||_infinity << n^r,                                    (8.3)
```

one has

```text
||x^alpha E_n||_p^p
 <= n^(-alpha p)||E_n||_infinity^(p-1)||E_n||_1
 << n^(r(p-1)-alpha p)||E_n||_1.                            (8.4)
```

To make the power in (8.4) nonpositive using only endpoint convergence one
needs

```text
alpha>=r(1-1/p).                                            (8.5)
```

The resulting detector boundary is at least

```text
alpha+1/p >= r+(1-r)/p.                                    (8.6)
```

For the natural `r=1` bound on `B_n`, this is `1`, giving only the already
known half-plane.  A strict gain `r<1` would give a strip, but that is an
arithmetic power saving, not a free consequence of weighting.

Logarithmic or other subpower weights do not move the boundary in (8.2),
but they also cannot pay the factor `n^(p-1)` in (4.7).  They become useful
only after a subpolynomial higher-moment bound has already been established.

## 9. Lorentz and Orlicz improvements: exact positive and negative results

The positive Lorentz result is (5.4): one fixed weak exponent `q>1` is
enough.  The subsequent R136 weak-tail audit strengthens the strategic
interpretation: unit increments turn such a weak exponent into a pointwise
power saving.  Endpoint Orlicz gains of logarithmic size are not.

In fact the known PNT estimates already imply, for every fixed `A>0`,

```text
integral_0^1 |M_1(theta)|
  [log(e+|M_1(theta)|)]^A dtheta < infinity.                 (9.1)
```

This follows from (2.5) and `M(n)<<_B n/(log n)^B` after choosing
`B>A+1`.  Hence every finite `L log^A L` bump is already available without a
fixed strip.  Such bumps do not embed in any `L^(1+delta)`.

The failure persists even after imposing the elementary structure of the
Mertens function.

### Proposition 9.1 (integer Lipschitz spike countermodel)

There is an integer sequence `A(n)` satisfying

```text
A(0)=0,
|A(n+1)-A(n)|<=1,
|A(n)|<=n,                                                   (9.2)
```

such that, for every fixed `B>0`,

```text
sum_n |A(n)|[log(e+|A(n)|)]^B/n^2 < infinity,               (9.3)
```

but, for every `p>1`,

```text
sum_n |A(n)|^p/n^2 = infinity.                              (9.4)
```

#### Construction and proof

Choose rapidly separated integers

```text
N_j=ceil(exp(exp(j^2))),
H_j=floor(N_j exp(-j^3)).                                   (9.5)
```

On a block of length `2H_j` near `N_j`, let `A` rise with slope `1` from
`0` to `H_j` and then fall with slope `-1`; put `A=0` elsewhere.  The blocks
are disjoint.  On the `j`-th block, `n` is comparable to `N_j` and

```text
sum_block |A(n)|^r/n^2 asymp H_j^(r+1)/N_j^2.               (9.6)
```

For `r=1`, adding a logarithmic power gives at most

```text
exp(-2j^3+Bj^2),                                            (9.7)
```

which is summable.  For `r=p>1`, the logarithm of (9.6) is

```text
(p-1)exp(j^2)-(p+1)j^3+o(1),                               (9.8)
```

so the individual block contributions tend to infinity.  This proves the
claim.

Thus integrality, bounded increments, the trivial linear envelope, and all
finite logarithmic moments do not self-improve.  Any successful theorem must
use structure specific to the increments `mu(n)`, not merely the regularity
of their partial sums.

## 10. The exact compact-collar arithmetic problem

The compact error `E_n` in (4.5) admits an exact discrete description.  Put
`t=1/x`.  The linear terms in the fractional parts cancel, so on every
interval `m<t<m+1`, `m>=n`, the error is constant:

```text
E_n(1/t)=D_n(m),                                             (10.1)

D_n(m)=1-sum_(k<=n) mu(k) floor(m/k)
          +n g(n)floor(m/n).                                (10.2)
```

Therefore

```text
||E_n||_p^p
 =sum_(m>=n) |D_n(m)|^p/[m(m+1)].                           (10.3)
```

The sequence `D_n` is periodic with period `lcm(1,...,n)`: translating `m`
by that period changes the two linear floor contributions by the same
quantity.  More importantly, the first collar has a very simple
coefficient-specific form.  The identity

```text
sum_(k<=m) mu(k)floor(m/k)=1                                (10.4)
```

gives, for `n<=m<2n`,

```text
D_n(m)=M(m)-M(n)+n g(n)=M(m)+n gamma(n).                    (10.5)
```

Thus the higher-moment problem is already visible on one dyadic Mertens
block:

```text
||E_n||_p^p
 >= c n^(-2) sum_(n<=m<2n)|M(m)+n gamma(n)|^p.              (10.6)
```

This rules out the hope that exterior tail cancellation alone has removed
the arithmetic difficulty.  It has converted it into a distributional
Mertens estimate with a canonical centering.

At the same time, (10.3) suggests a precise distributional route through the
centered collar.  It would suffice to prove, for one `q>1`,

```text
sup_n sup_(U>0)
 U^q sum_(m>=n: |D_n(m)|>U) 1/[m(m+1)] < infinity.           (10.7)
```

Then (5.3) and `||E_n||_1->0` prove a fixed strip.  Estimate (10.7) is a
signed, coefficient-specific large-deviation theorem for a Möbius divisor
floor sum.  It is not supplied by positivity, the PNT, or known
Vinogradov--Korobov bounds.

The most plausible tools for (10.7) are dyadic mean values of (10.2), the
quotient grouping implicit in (10.4), and estimates that retain the joint
Möbius signs rather than bounding each floor block separately.  The first
collar (10.5) is the fail-fast test for any proposed argument.

## 11. Cross-check with current moment literature

The 2022 work of Alouges--Darses--Hillion similarly splits generalized
Nyman criteria into an unconditional approximation step and a coefficient
control step; their Gram/Hankel structure does not provide the missing
fixed higher moment.

A July 2026 preprint of Verjovsky gives a parallel local-moment formulation
for the Möbius Fourier polynomial

```text
P_N(t)=N^(-1/2)sum_(n<=N)mu(n)exp(2 pi i n t).               (11.1)
```

Its elementary local moment-to-point estimate implies that a subpolynomial
bound for one fixed local `q`-moment on an arc of length `1/N` gives a fixed
power bound for `M(N)`; arbitrarily large `q` are needed only to reach RH.
This is consistent with the present conclusion: one fixed nontrivial moment
is enough for a fixed strip.  Global Parseval does not control that critical
arc, so the preprint does not supply the needed estimate.  We use it only as
a cross-check, not as an imported proof lemma.

## 12. Verdict and next theorem

The fixed-strip Nyman route should not be demoted for the reason given in the
earlier RH audit.  Its correct status is:

1. The exact endpoint `L1` statement is known from the PNT.
2. Any fixed gain above exponent `1` proves the desired fixed strip.
3. Generic self-improvement is impossible, even with integrality, bounded
   increments, and every finite logarithmic Orlicz bump.
4. Every fixed dilation-equivariant linear smoother is identically zero.
5. Tail cancellation and power weights relocate or pay back the defect.
6. A coefficient-specific weak higher-moment theorem remains open, but for
   the direct Mertens tail its existence is equivalent to some pointwise
   power saving once unit increments are used.

The direct target (5.5) asks for `q>1` such that large values of `M(n)` have
`U^(-q)` reciprocal-measure tails.  It is now classified as an alternate
form of a pointwise fixed-power problem, not a lower-strength escape.  The
natural-approximant version is (10.7), with (10.5) as its mandatory first
test.  Either theorem would give a fixed uniform zero-free strip immediately
through the already published arithmetic Nyman--Beurling lemmas.

Nothing here proves that a fixed strip exists, and failures of the generic
self-improvement mechanisms do not prove that it does not exist.
